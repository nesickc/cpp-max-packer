## Scope and observable outcome

Deliver a native Windows Tauri/Rust application with a React/Three.js viewer.
Import a user-selected STL with explicit units; inspect native diagnostics;
choose box dimensions, separate clearances, fixed/cube orientation, pitch and
CPU search budget; Start and Stop; inspect the complete validated packing;
Save/Open a portable `.spectrapack` archive; export JSON plus authoritative
assets and checked packed STL plus its per-copy companion.

UI-01–UI-03 and DATA-02 are the primary linked requirements. DATA-03, GEO-02,
GEO-04/GEO-06 and DATA-01 constrain the implementation. This is partial coverage
of AT-13–AT-15, not completion of those gates or M3. Source/accepted bytes,
physical dimensions, original source frame and native validity stay authoritative.
Only a full `valid` pass permits an active restored/result snapshot.

Included: fixed bundled engine, scoped dialogs/files, nonblocking native work,
explicit CPU/manual pitch display, immutable settings/result association,
terminal snapshot viewer, native Stop-and-keep, shared preview geometry,
transparent box, orbit/pan/zoom/fit, dimensions, clipping and copy selection,
view-only hiding, minimal portable Save/Open, and native revalidation/re-export.

Remaining after this task: STL-container desktop journey; repair proposal UI;
full preset and automatic resource resolution; progress/incumbent event stream;
service job lifecycle/replay; continued search; periodic atomic checkpoints and
crash recovery; complete Start-to-terminal budget accounting; screenshots;
full-resolution selected-copy/LOD switching; offline installer prerequisite
qualification; Windows 10/11 clean-machine runtime gates; AMD viewport metrics.
The existing solve search-budget boundary must be labeled accurately. Archive
Save/Open covers portable complete state, not runtime checkpoint continuation.

## Test-first sequence

Tests below are planned gates, not observed outcomes. Record exact actual
commands, build/tool versions, intended failing assertion, successful rerun and
artifact paths. New tooling commands are defined by their implementation before
being claimed here. Keep complete logs in `.local/t008/`; filtered output cannot
establish success. Documentation/schema edits need structural validation, not
an invented product red run.

1. **Schema/adapter contract — DATA-01/UI-01.** Add direct fixtures for all
   command DTOs, nullable state, explicit custom units, invalid seeds/numbers,
   wrong/extra fields and unsupported desktop/project versions. Generate
   Desktop types from the same schema. First native tests should fail because
   prepare/restore commands and Stop hook are unavailable, not because a
   compiler/tool is absent. Preserve existing contract checks and capabilities.

2. **Native prepare/restore/export — GEO-02/GEO-06/DATA-03, AT-14 subset.**
   Use an analytic asymmetric box with a nonzero source origin and explicit
   non-mm units. Obtain a real accepted inspection report, prepare settings,
   solve through the actual engine, restore in a different directory, and
   export without starting a second solve. Compare retained copy IDs, ordered
   poses, source/accepted hashes, catalog identity, settings and measured
   provenance. Independent coordinate arithmetic checks source-to-local and
   a quarter-turn placement; reread binary STL float32 vertices/count/ranges.
   Also round-trip an existing explicit accepted repair record. Corrupt source
   hash, accepted PLY, report repair evidence, matrix, count, quaternion,
   constraints/catalog and result bindings independently; each must reject.
   Invalid/indeterminate physical validation cannot yield an active result.

3. **Cooperative Stop — SOL-06/UI-03, AT-13 subset.** In a real long bounded
   CPU solve, wait for actual native work, request Stop through the production
   Rust path and measure receipt latency (≤250 ms for the qualified test).
   Verify the UI/state path remains usable, the operation stays stopping until
   native completion, and a terminal retained result passes fresh validation.
   Exercise preexisting marker, Stop while preparing, repeated Stop, stale IDs,
   natural-completion race and child failure. A killed process is not a passing
   Stop test. No fabricated checkpoint/restart claim.

4. **Portable archives — DATA-02, AT-14 subset.** Save a real accepted object
   and result, move the archive to a different Unicode/spaced directory, open
   through production Rust plus native restore, and compare source/accepted
   bytes and physical/provenance values. Save an accepted object before its
   first result as well. Save edited pending controls before Start and confirm
   they reopen separately from result settings. Reject Save after replacing
   the imported object while retaining a result for another object. Include
   repaired/unrepaired native fixtures. Reject
   traversal, absolute/UNC/drive paths, ADS/device names, duplicate case-folded
   entries, links, truncated ZIPs, changed hashes/matrices, unsupported version,
   excessive sizes and mismatched resolved settings. Inject failure before
   archive replacement and during staged restore; the previous saved archive
   and current active result must survive. Use ZIP and hashes as independent
   transport checks; native validation establishes physical permission.

5. **Viewer/state — UI-02, AT-14/AT-15 subset.** Before UI implementation, add
   a numeric transform test whose hand-computed asymmetric, off-origin,
   nonidentity rotation result cannot pass via identity/transposition errors.
   Compare the Three instance transform to native JSON/STL coordinates. Check
   no second source-to-local conversion, unit instance scale and Z-up box
   bounds. Stale state revisions, replacing imports, pending settings and old
   results must remain associated correctly. Hide/select/clip and prove count,
   copy IDs, poses and export inputs are unchanged. Shared geometry count must
   remain one irrespective of instance count. These tests do not prove GPU
   frame-time performance.

6. **Real native desktop journey — UI-01–UI-03.** Launch the built Tauri
   executable against its fixed staged engine; import the analytic fixture,
   set box/clearances, run, inspect, Stop a subsequent run, Save, move/Open and
   export. Repeat a modest practical accepted `rc/` object with preserved hash
   and actual native validity. Exercise invalid import, bad settings, failed
   Open and failed STL publication while retaining valid JSON. Verify actual
   keyboard focus, resize and viewer interaction during native work. Record
   screenshots/manual interaction evidence or available native WebDriver
   evidence; a browser page with mocked invoke calls does not pass this gate.

7. **Security/package checks — SYS-01/SYS-04.** Build with bundled UI assets
   and fixed sidecar. Check that production custom commands cannot launch
   arbitrary programs, read arbitrary files or write outside dialog grants.
   Test path/reparse/hardlink aliases at the actual boundary. Verify startup
   from a different working directory, missing/wrong sidecar errors, no browser
   shell/fs grants and no remote production UI dependency. A local staged run
   is not clean-machine/installer qualification.

Run the affected existing native Debug/Release contracts, import, solve control,
result-builder/export gates and schema checks. Broaden only for changed native
behavior or unresolved failures; do not rerun unrelated heavy benchmarks merely
to increase counts. Obtain an independent critical review for restore validity,
immutable-state replacement and cancellation races; address concrete findings
before final native desktop acceptance.
