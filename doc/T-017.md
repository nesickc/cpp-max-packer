# T-017: unified CLI/stdio jobs, standalone validation and Continue

Status: planned; no implementation or passing evidence claimed.
Proposed branch: `feature/DATA-01-job-lifecycle` (not created).
Prerequisites: [T-010](T-010.md), [T-015](T-015.md) and [T-016](T-016.md), merged into `main`.
Start the branch only after those prerequisites and this planning change merge.
Follow [MILESTONES.md](MILESTONES.md) and [ADR 0011](../spec/decisions/0011-cpu-first-follow-up.md).

## Scope and boundary

Implement required headless `pack`, standalone `validate`, and real `serve --stdio`
job methods using the same schemas/solver/output as desktop Start. Complete
scoped asset import/repair, preflight, status, stop, Continue, project and result
methods from §8.1. Keep auxiliary commands documented deliberately. The required
`benchmark` command is T-022; periodic checkpoints/crash recovery are T-018,
Auto GPU fallback T-020 and live viewer delivery T-021. This ticket alone does
not establish full AT-13 or process-interruption recovery.

## Governing requirements

DATA-01/DATA-02/DATA-03, SOL-01/SOL-06/SOL-07/SOL-08 and UI-03;
AT-06/AT-13/AT-14/AT-16 subsets. Canonical spec §§7.1–7.2, 8.1–8.5 and
10.1, plus ADR 0004's framing/replay contract, govern M1/M3 command integration.

## Observable acceptance

1. **T017-A1:** CLI `pack` and service `job.start` produce the same resolved
   physical problem and validated contract. Implement every required §8.1 method;
   capabilities distinguish commands/methods. No unsupported path fabricates success.
2. **T017-A2:** Exercise created/preparing/running/stopping/finished/failed states,
   status queries, CLI Ctrl+C and Stop-and-keep. Acknowledge within 250 ms and
   ordinary safe Stop within 5 s on qualified hosts; preserve Start-origin budgets.
   Long calls keep the UI usable; durable forced-termination recovery remains T-018.
3. **T017-A3:** Enforce one active solver and bounded request replay without ID
   eviction. Duplicate requests do not duplicate work; cache exhaustion closes
   explicitly. Emit ordered job sequences and immutable validated revisions.
4. **T017-A4:** Test UTF-8 NDJSON, protocol-only stdout and stderr logs; malformed
   complete records recover, while oversized 1 MiB records/nonempty EOF fragments
   close with exit 2. Cover CR/LF byte limits, untrusted null IDs, bad schemas,
   unknown methods, handle/session mismatch, scoped paths and replay conflicts.
5. **T017-A5:** Continue adds a recorded segment/budget without reducing count.
   Preserve geometry, units, container, gaps and rotation permissions; changes
   require a new job. Retain segment settings/backend/RNG/thread/parent provenance;
   incompatible search state becomes an explicitly reported valid warm start.
6. **T017-A6:** Standalone `validate` independently checks restored authoritative
   assets, all poses and actual STL copy ranges/coordinates. Invalid/indeterminate
   validation exits 5. Check all §8.1 exit codes, including valid empty/stopped
   results and fatal errors retaining a valid incumbent without hiding the error.
7. **T017-A7:** Dropped/coalesced/stale events and UI reconnects cannot corrupt
   best state; status restores the complete association. Use asynchronous scoped
   geometry files, never massive wire arrays or shell-interpreted arguments.

## Tests, evidence and review

Use real process/service/native red/green cases and the standalone validation
adversaries, not mocked lifecycle success. Retain full records, exit codes,
counts/poses, timings and failure logs under `.local/t017/`; apply shared rules.
Architect review freezes job/asset ownership and schemas before edits. Routine
contract review and critical shared-state/cancellation review cover affected risks.

## Open decisions and compatibility

Settle auxiliary-command compatibility, job-file/segment contracts, desktop adapter
migration and exact/reset continuation keys before edits. Generate types after
schema changes. In-memory lifecycle success is not durable-checkpoint evidence;
leave the T-018 portion of AT-13 explicitly open until it passes.
