# T-021: deferred live viewer, full-resolution inspection and PNG

Status: planned; **low delivery priority**, no passing evidence claimed.
Proposed branch: `feature/UI-02-live-viewer-inspection` (not created).
Prerequisites: [T-013](T-013.md), [T-017](T-017.md) and [T-018](T-018.md), merged into `main`.
Start the branch only after those prerequisites and this planning change merge.
Schedule after CPU/practical packing, repair and count work. This does not block
T-019/T-020. [MILESTONES.md](MILESTONES.md) and ADR 0011 fix that priority.

## Scope and boundary

Complete the viewer with live validated revisions, selected-copy full/LOD
inspection, viewport PNG and required navigation/keyboard controls. Keep one
shared object mesh plus instance transforms; load full geometry only for selected
inspection. View operations cannot change authoritative assets, poses or count.
Candidate/debug views, if provided, are separately labeled unvalidated and cannot
be exported as the best result. Manual placement editing and new search are outside scope.

## Governing requirements

UI-01/UI-02/UI-03, GEO-02/GEO-04 and DATA-03; AT-05/AT-14/AT-15 and
AT-13/AT-16 subsets. Canonical spec §§5.1–5.2, 7.1/7.3, 8.1/8.3/8.5
and 10.1 govern remaining M3 interaction and M6 viewport evidence.
[ADR 0011](../spec/decisions/0011-cpu-first-follow-up.md) preserves deferred delivery.

## Observable acceptance

1. **T021-A1:** Each visible best packing is one complete immutable validated
   revision. Ignore stale job/revision events, coalesce obsolete meshes/poses and
   deliver progress/preview at no more than 4 Hz; count never decreases for the job.
2. **T021-A2:** Reconnect/restart the UI and drop progress events without losing
   settings/result association. Status/recovery restores the latest complete best;
   failed preview delivery cannot declare valid geometry invalid or block CPU export.
3. **T021-A3:** Support orbit/pan/zoom, fit/reset, orthographic/perspective, axes,
   scale/grid, transparent container/edges, movable clipping, copy selection,
   isolation/hiding, stable IDs and translation/quaternion inspection. Test keyboard focus.
4. **T021-A4:** Toggle selected-copy full-resolution inspection and interactive
   shared LOD. Actual error-limited triangle count is visible; unsuccessful
   simplification cannot force deletion of features. Accepted hashes, fields,
   deterministic counts/poses, validation and export remain unchanged by display settings.
5. **T021-A5:** Verify nontrivial source frames/rotations against JSON and exported
   vertices. Hiding/clipping affects only the view, never saved count or poses.
   Export the current-view PNG with count/settings companion metadata and checksum.
6. **T021-A6:** On the qualified AMD host, orbit 1,000 copies sharing a
   20,000-triangle LOD at 1080p for a recorded 10 s: median frame time <=33 ms,
   p95 <=50 ms. Report hardware/driver, scene, interaction and raw frame timings.
7. **T021-A7:** Resize/move/focus and Stop remain usable during heavy work/export.
   Measure Stop acknowledgement <=250 ms during live revision churn and the
   qualified 1,000-copy viewer workload; interactivity alone cannot pass this check.
   Graphics acceleration failure may degrade rendering but preserves CPU solve and
   export. Complete box/STL/repaired-project journeys, screenshots and error recovery.

## Tests, evidence and review

Use practical revision/transform/native desktop red/green cases plus manual visual
interaction checks. Screenshots do not establish physical validity; independently
check saved/exported poses. Retain raw frame timings and complete logs under
`.local/t021/`; the canonical 10-second viewport gate is not replaced by an FPS estimate.
Routine UI/contract review applies; shared revision lifetime needs architect design
and focused concurrency review when ownership is consequential.

## Open decisions and compatibility

Freeze revision fetching/cancellation, mesh lifetime, selected full-mesh reserves,
PNG metadata and desktop DTO migration before edits. Preserve T-017/T-018 engine
state ownership; do not create a separate viewer incumbent/cache authority.
Existing project/result identities remain authoritative throughout display changes.
