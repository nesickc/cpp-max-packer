## Observable acceptance

- Generate one immutable display mesh shared by copies. Default simplification
  targets 20,000 triangles with a 0.1 mm approximate display-error setting;
  report actual count and measured approximation rather than forcing the target.
- Changing display settings preserves accepted coordinates and hashes, voxel
  fields and authoritative validation. Display meshes cannot enter authoritative
  validation or replace the source of a field.
- Voxelize accepted solids directly using one physical pitch and explicit grid
  axes, origin, cell-boundary convention and trimmed kernel origin. Exact
  analytic fixtures check solid interiors, cavities, thin features, negative
  origins, grid alignment and rotations. Unknown cells remain occupied/blocked.
- Container masks certify whole cells inside the wall-eroded permitted volume.
  Placed-object masks use full one-sided Euclidean pair-clearance dilation,
  including fractional clearances. Pair and wall offsets remain independent.
- Adding/removing copies uses bounded reference counts; removing one copy never
  clears another copy's overlapping clearance region. Off-grid poses must be
  revoxelized without silently changing physical transforms.
- Preflight checks arithmetic and storage before large allocations. Work, memory
  and cache bounds produce explicit failures; manual pitch and physical geometry
  never change to make a request fit.
- A generated closed subdivided mesh with at least one million triangles and a
  thin-feature fixture exercise the large-mesh boundary. Practical regressions
  use unchanged accepted `rc/` sources and independently known field predicates.
