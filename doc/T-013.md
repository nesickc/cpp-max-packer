Status: planned; no implementation or passing evidence claimed.

## Scope and boundary

Complete the desktop journey with a closed STL representing usable interior
volume, alongside the existing analytic box. Reuse native accepted-solid
containment and clearance; expose independent container import, units,
diagnostics, bounds and transparency. Preserve concavities and excluded cavities.
Multi-object packing, container resizing to fit, and new repair algorithms are
outside this ticket. Live revisions and selected full-resolution viewing are T-021.

GEO-01/GEO-02/GEO-03/GEO-05/GEO-06, UI-01/UI-02 and DATA-02/DATA-03;

## Observable acceptance

1. **T013-A1:** Import object and container with independently recorded units
   and source mappings. Show physical bounds and native diagnostics before Start.
   Invalid, indeterminate or ambiguous containers cannot authorize a solver job.
2. **T013-A2:** In a U-shaped permitted volume, reject a bridge whose vertices
   lie in the arms but whose middle exits the volume. Reject an object enclosing
   an excluded cavity without crossing its surface; accept prescribed valid poses.
3. **T013-A3:** Pack into accepted concave/cavity fixtures and supplied accepted
   containers under pinned settings. Validate all poses against authoritative
   container material, separate pair/wall gaps, and the independent numerical rule.
   Positive profiles require prescribed nonempty witness counts; a zero result
   cannot pass them. Derive practical lower bounds from independently valid poses.
4. **T013-A4:** Changing container, units or clearances creates pending settings
   for a new job. Previous results retain their producing settings and hashes;
   prepared fields invalidate correctly, and physical geometry never shrinks.
5. **T013-A5:** Save, move and reopen a project containing both assets, including
   an explicitly accepted repair. Preserve source/accepted hashes, repair evidence,
   container semantics and transforms; tampering fails before incumbent admission.
6. **T013-A6:** JSON, viewer and re-read full-resolution STL coordinates agree
   for nontrivial source origins and rotations. Export remains streamed, checks
   actual quantized per-copy geometry, and retains valid JSON if STL checking fails.
7. **T013-A7:** Complete box and STL desktop journeys with keyboard controls,
   actionable import/resource errors and responsive Stop. Valid empty results are
   labeled `best_found`; a failed search is not evidence of impossibility.

## Tests, evidence and review

Use spec-linked red/green native/Rust/desktop cases, independent analytic poses,
and manifest-pinned `rc/` regressions. Screenshots establish controls, not validity.
Retain settings, counts/poses, hashes, actual commands and complete logs under
`.local/t013/`; apply the shared evidence rules in MILESTONES.md.
Freeze ownership/DTO changes with an architect. Use critical geometry review for
containment/frame authorization changes; routine review covers integration.

actual native desktop/project/export evidence above, not container-preview success.
